API reference#

pystiltctl is used from its command line (Command line); these are the functions behind it.

Project inputs#

inputs.project_key(project)

Return project in the form every spelling of one project shares.

inputs.push(project, url)

Copy a project's inputs to url.

inputs.pull(url, directory)

Copy a project's inputs from url into directory.

inputs.is_local(location)

Whether location is a path on this machine rather than a URL.

inputs.local_path(location)

Return a local location as a path, without a file:// in front.

inputs.project_name(location)

Return a project's name, the last part of its folder or URL.

inputs.put(directory, url, name)

Copy one file of a project folder back to url, such as a grown receptors.csv.

Worker#

worker.run_task(project, n_tasks, *[, ...])

Run task index of n_tasks of project, in place of this process.

worker.task_index([index])

Return this pod's task index: index, or else $JOB_COMPLETION_INDEX.

worker.project_directory(project, workdir)

Return the local project folder for project, pulling its inputs if needed.

worker.stilt_command(directory[, task, ...])

Return the stilt run command line for a share of a project.

worker.become(command)

Replace this process with command, so its exit code and signals are this pod's.

worker.run(command)

Run command and return its exit code, passing this process's stop signals on to it.

Kubernetes Job#

job.JobSpec(project, name, tasks, parallelism)

What the Job for a project runs, and with what.

job.Volume(claim, path)

A PersistentVolumeClaim mounted in every pod.

job.job_spec(project, *[, tasks, ...])

Return the Job for project, from its config.yaml and these overrides.

job.manifest(spec)

Return the indexed Job that runs spec, as a Kubernetes manifest.

job.cron_job(spec, delay[, render])

Return the CronJob that runs pystiltctl tick for spec every hour.

job.create(job)

Create job on the cluster kubectl points at, and return its name.

job.apply(manifest)

Create manifest, or update it if it exists, and return its name.

job.to_yaml(job)

Return job as YAML, in the order it was written.

job.default_image([version])

Return the image matching this pystiltctl.

job.kubernetes_memory(mem)

Return a Slurm memory size, such as 8G, as a Kubernetes quantity.

job.label_value(name)

Return name as a Kubernetes label value and name prefix.

Status#

status.simulations(project, *[, output])

Return stilt status --json for project, a URL or a local folder.

status.project_jobs(project, *[, namespace])

Return the summaries of project's Jobs, oldest first, and the Jobs left out.

status.job_summary(job)

Return the facts about one Job, from kubectl get job -o json.

status.report(data, jobs[, unclaimed])

Return the text pystiltctl status prints.

status.count_indexes(indexes)

Return how many task indexes a Job's index list holds, such as 0-3,7.

Schedule#

schedule.tick(project, *[, delay, now, ...])

Add the hours now due to project, then run its last day.

schedule.due_hours(now[, delay])

Return the hours a tick at now covers, oldest first, in UTC.

schedule.read_sites(directory)

Return the sites in a project's sites.csv.

schedule.hourly_receptors(sites, hours)

Return a receptor for each site at each hour, hour by hour.

Images for web maps#

render.render(directory, url, receptor_ids, *)

Draw the finished footprints of receptor_ids to url, and add each to its day's index.

render.choose_variant(project[, variant])

Return the variant whose footprints to draw: variant, or the project's only one.

render.image(foot)

Return the footprint as an RGBA image, north at the top, rows in web Mercator.

render.png(foot)

Return image() as PNG bytes.

render.bounds(foot)

Return the footprint grid's outer corners, [[south, west], [north, east]].

render.entry(receptor, foot)

Return what the JSON beside a footprint's image says about it.

render.utc(time)

Return time as text with its zone: UTC, ending in Z.

render.mercator_y(lat)

Return web Mercator's y for latitudes in degrees, in units of the Earth's radius.
